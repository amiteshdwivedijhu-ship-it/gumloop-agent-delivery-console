Process to automate Mapped

1Call ends in Salesloft and the transcript lands in Slack #call-notes.
↓
2An agent extracts contact, deal, stage, summary, next step from the transcript.
↓
3Agent updates HubSpot and files a cited artifact with the source lines.
↓
4#crm-updates gets a one-line summary per call. Ops never opens the CRM.

Iterate the skill before production

Validation run on 48 transcripts: 42 correct, 6 mis-mapped the deal stage. The mis-maps cluster on calls that discuss proposals.

1 · Retrain on the 20 flagged transcripts sampled with Priya.
2 · Verify stage changes against Meridian's HubSpot property list before writing.

Skill v2 staged: retrained + verification node. Recheck shows 0 mis-maps. Recommended before deploy, not blocking.

Platform gap: multi-part Slack threads

On Meridian's workspace plan, the Slack trigger watches new threads but cannot follow replies across channels. Multi-step approvals (deal desk) would fail mid-run.

Impact: the two-approval deal flow is a stated requirement in the MSA scope.
Workaround: deploy the single-channel trigger now; approvals enforced via HubSpot tasks.
Filed · GL-4821 · run logs and MSA scope attached. Product triage Tuesday. Deploy path is unchanged.
